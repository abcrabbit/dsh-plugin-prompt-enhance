# 提示词增强

在输入框发送按钮旁增加一个橙色增强按钮，用默认模型把草稿改写成更清晰的提示词。

Adds an orange Enhance button beside the composer's send action that rewrites the draft into a clearer prompt with the default model.

## 安装

**方式一（推荐）**：在 DSH 插件的「发现」页添加索引源

```
https://raw.githubusercontent.com/abcrabbit/dsh-plugin-index/main/index.json
```

然后搜索并安装本插件。

**方式二（手动）**：下载本仓库，在 DSH「设置 → 插件 → 添加插件 → 本地目录」中选择本目录。

## 兼容性

- DSH 0.2.2 系列（在 `0.2.2-rc.5` 上验证）
